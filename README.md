# Chess Puzzle Visualization

A Chess.com-inspired Puzzle Rush analytics dashboard built with Next.js, React 19, TypeScript, Tailwind CSS, Radix UI, React Query, D3.js, Storybook, Vitest, Jest, and Playwright.

## Features

- Mock Puzzle Rush performance dataset with ratings, accuracy, streaks, and solved puzzle trends
- Responsive Chess.com-style analytics dashboard
- D3 chart components for score over time and difficulty distribution
- React Query for data fetching and query management
- Storybook stories for core UI components
- Tests with Vitest, Jest/React Testing Library, and Playwright end-to-end coverage

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open Storybook:

```bash
npm run storybook
```

Run tests:

```bash
npm run test
npm run test:jest
npm run playwright
```

Build for production:

```bash
npm run build
```
